**Hana**は、カナデ（Kanade）とハジャ（Hari）を自分のコンピューターで実行するプログラムです。このドキュメントの実行ボタンやプレイグラウンドはブラウザの中で動くエンジンなので、コンピューターのファイルやネットワークには触れませんが、Hanaはターミナルで実行するプログラムなので、そうしたこともできます。そのため、このドキュメントで「ブラウザでは使えません」と書かれている道具は、すべてHanaランタイムで実行するときに使うものです。

HanaはGoで作られていて、インタープリタ、バイトコードコンパイラとVM、コマンドラインツール、言語サーバーが1つの実行ファイルに入っています。ソースコードは[github.com/soumt-r/hana](https://github.com/soumt-r/hana)にあり、MITライセンスで公開されています。

### できること

| コマンド | できること |
| --- | --- |
| `hana run ファイル.knd` | カナデ（`.knd`）、ハジャ（`.hr`）、コンパイル済みのバイトコード（`.hn`）を実行します |
| `hana build ファイル.knd` | バイトコード（`.hn`）にコンパイルして保存します |
| `hana pack ファイル.knd` | プログラムを1つの実行ファイルにまとめます。ほかのOS用も作れます |
| `hana add パス` | 他の人が作ったパッケージをプロジェクトに追加します（`install`、`remove`、`list`もあります） |
| `hana init フォルダ` | スタートファイルのある新しいプロジェクトを作ります |
| `hana lsp` | エディターで補完やエラー表示をしてくれる言語サーバーを実行します |

`hana run`は、標準ではより速いバイトコードコンパイラとVMで実行し、バイトコードが対応していない機能を使ったプログラムならツリーウォーク方式のインタープリタで実行します。`--tree`を付けるとツリーウォーク方式のインタープリタで、`--bc`を付けると切り替えずにバイトコードだけで実行します。2つの方式は同じ結果になるように作られています。

| ドキュメント | 内容 |

### ブラウザではできないことをする道具

| 道具 | できること |
| --- | --- |
| [ファイルを扱おう](/docs/hana/files) | `【ファイル】`モジュールでファイルとフォルダを読み書きします |
| [ソケットで会話しよう](/docs/hana/sockets) | `【ソケット】`モジュールでネットワークを通して文字列をやり取りします |
| [Webのアドレスから取ってこよう](/docs/hana/http) | `【HTTP】`モジュールでWebサーバーにリクエストを送ります |
| [タイムゾーン](/docs/hana/timezone) | `timezone`パッケージで都市ごとに違う時刻を扱います |

`【数学】`、`【テキスト】`、`【パス】`などのほかの標準モジュールは、ブラウザでもHanaでも同じように動きます。それらの道具は[基本文法チュートリアル](/docs/tutorial/10-stdlib)にあります。

### 信用できないスクリプトを動かすとき

Hanaは標準でファイルとネットワークへのアクセスを許可します。人からもらったスクリプトを動かすときは、`--allow-file=false`でファイルアクセスを、`--allow-net=false`でネットワークアクセスを止められます。詳しくは[ファイルを扱おう](/docs/hana/files)と[ソケットで会話しよう](/docs/hana/sockets)の最後の節にあります。

### エラーもヘルプも自分の言語で

Hanaが表示するヘルプとエラーの文言は、韓国語と日本語に対応しています。スクリプトが出したエラーはそのスクリプトの言語（ハジャは韓国語、カナデは日本語）で表示され、コマンドラインのヘルプは`--locale ko`か`--locale ja`、環境変数`HANA_LANG`、システムの言語の順に決まります。
