title: 7. 繰り返し文 (繰り返そう)
description: 同じことを何度も繰り返してみましょう。
---

同じコードを百回、千回もコピーして貼り付けることはできませんよね？繰り返し文を使えば、コードをとても簡潔にまとめることができます。
一番簡単な「決まった回数だけ繰り返す」をやってみましょうか？

```kanade
1から3まで繰り返そう(『回数』):
    枠「現在の回数:{『回数』}」を出力しよう
```

特定の条件が満たされている間だけ、ずっと繰り返すようにすることもできますよ。「〜間繰り返そう:」の構文を使って、エネルギーがすべてなくなるまで繰り返してみましょう！

```kanade
『エネルギー』を【数字】の3にしよう

(『エネルギー』が0より大きい)間繰り返そう:
    枠「エネルギー残り:{『エネルギー』}」を出力しよう
    『エネルギー』から1を引こう
    
「エネルギーがすべて尽きました！」を出力しよう
```

配列(リスト)の中に入っているデータを一つずつ取り出しながら繰り返すこともできますよ。とても便利によく使われる方法ですね。

```kanade
『果物たち』を【(文字列)リスト】の【「りんご」,「バナナ」,「ぶどう」】にしよう

『果物たち』の『果物』ごとに繰り返そう:
    枠「美味しい{『果物』}です！」を出力しよう
```

### 繰り返しの途中で終わる

`繰り返しを終わろう`に出会うと、一番内側の繰り返しからすぐに抜け出します。欲しいものが見つかったら、それ以上回る必要がないので便利です。

```kanade
1から10まで繰り返そう(『数』):
    もし(『数』が4と同じだ)なら:
        繰り返しを終わろう
    枠「{『数』}回目の挑戦」を出力しよう
```

### 逆から数える

開始の数が終わりの数より大きいと、1つずつ減りながら繰り返します。終わりの数も含むので、`3から1まで`は3、2、1です。

```kanade
3から1まで繰り返そう(『数』):
    『数』を出力しよう
「発射！」を出力しよう
```

### 文字を1つずつ取り出す

文字列もリストのように、`ごとに繰り返そう`で文字を1つずつ取り出せます。

```kanade
『あいさつ』を【文字列】の「こんにちは」にしよう

『あいさつ』の『文字』ごとに繰り返そう:
    枠「文字: {『文字』}」を出力しよう
```

### 繰り返しの中で作った変数と外の変数

繰り返しは、**回るたびに新しい空間**を開きます。繰り返しの中で最初に作った変数は、その繰り返しが終わると消えて、繰り返しの外では使えません。

```kanade fail
1から2まで繰り返そう(『回数』):
    『二乗』を【数字】の(『回数』 * 『回数』)にしよう
『二乗』を出力しよう
```

繰り返しが終わったあとも値を使いたいなら、繰り返しの**前で**変数を作っておいて、中ではその変数を変えます。

```kanade
『合計』を【数字】の0にしよう

1から4まで繰り返そう(『数』):
    『合計』に『数』を足そう

枠「1から4までの合計: {『合計』}」を出力しよう
```

### 繰り返しの中で変えても回る回数は同じ

`1から10まで`のように数字を書くこともできますし、`1から『終わり』まで`のように<strong>変数や式</strong>を終わりの値(始まりの値も)として使うこともできます。

繰り返しが始まるときに、回る回数が決まります。終わりの値は始まるときに一度だけ読まれるので、繰り返しの中で『終わり』を変えても回る回数は同じです。繰り返しの中で『回数』のような繰り返し変数を変えても、変わるのは<strong>その回の値だけ</strong>で、次の回には元の数え方の次の数字が入ります。

```kanade
『終わり』を【数字】の3にしよう

1から『終わり』まで繰り返そう(『回数』):
    枠「{『回数』}回目」を出力しよう
    『回数』に10を足そう
    『終わり』に1を足そう
```

`ごとに繰り返そう`も、始まったときのリストのまま回ります。繰り返しの中でそのリストに項目を追加しても、新しい項目は回らないので、終わらない繰り返しにはなりません。

```kanade
『数たち』を【(数字)リスト】の【1,2,3】にしよう

『数たち』の『数』ごとに繰り返そう:
    『数たち』の後に『数』を追加しよう

枠「個数: {『数たち』の『長さ』}」を出力しよう
```
