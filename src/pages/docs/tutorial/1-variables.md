プログラムはデータを覚えることから始まります。Kanadeは『』を使って名札を作ることができますよ。
まずは、一番基本的な名札を作ってみましょうか！

```kanade
『名前』を【文字】の「ホン・ギルドン」にしよう
枠「こんにちは、{『名前』}さん！」を出力しよう
```

数字も保存できますよ！ 

```kanade
『年齢』を【数字】の20にしよう
枠「年齢は{『年齢』}歳です。」を出力しよう
```

もしデータの形（タイプ）を省略したらどうなるでしょうか？Kanadeは自動的に【何でも】タイプとして柔軟に処理してくれます。動的スクリプトのように軽くコーディングできるんです！

```kanade
『あだ名』を「空」にしよう
枠「私のあだ名は{『あだ名』}です。」を出力しよう
```

絶対に変わらない値もあります。このような値は`固定しよう`を使って、定数というものにすることができるんですよ。一度固定すると後から変えることはできません。

```kanade
『円周率』を【数字】の3.14に固定しよう
枠「円周率は{『円周率』}です。」を出力しよう
```

まだ何も決まっていない時は`空っぽ`を使うことができます。後から値を入れる時に便利ですよね？

```kanade
『結果』を空っぽにしよう
枠「現在の結果は{『結果』}の状態です。」を出力しよう
```

---

### 改行なしで出力する & 値を入力してもらう

画面に文字を出力する時、改行せずに続けて出力したいなら`続けて出力しよう`を使えばいいです。
そして、ユーザーに直接値を尋ねたい時は`入力してもらおう`を使います！指定した【タイプ】で自動変換もしてくれるんですよ。

```kanade
「あなたの名前は何ですか？」を続けて出力しよう
『ユーザー名』を【文字】で入力してもらおう
枠「お会いできて嬉しいです、{『ユーザー名』}さん！」を出力しよう
```

---

### 固定された値を変えようとしたらどうなるでしょうか？

先ほど`固定しよう`で作った値は絶対に変えられないと言いましたよね？もし無理やり変えようとしたらどうなるか、一度テストしてみましょうか！

```kanade fail
『誕生日』を【文字】の「1月1日」に固定しよう
「私の誕生日は」を続けて出力しよう
『誕生日』を出力しよう

(参考)あっ！固定された誕生日を勝手に変えようとしています！
『誕生日』を【文字】の「2月2日」にしよう
```

このコードを実行してみると、<strong>"定数 '誕生日' の値は変更できません。"</strong>というエラーが出るはずです。このようにKanadeは大事な値が間違って変わらないように、しっかり守ってくれるんです！

---

### 型変換ユーティリティ (データの形を変える)

時には文字を数字に、数字を文字に変えたい時がありますよね？Kanadeはデータを変換する便利な組み込み関数を提供しています。

* 〈文字列に〉: 数字や他のデータを文字列に変えてくれます。
* 〈数字に〉: 文字列を計算できる数字に変えてくれます。
* 〈コードに〉: 文字のアスキー/ユニコード番号を教えてくれます。
* 〈文字に〉: アスキー/ユニコード番号を再び文字に変えてくれます。

```kanade
『文字』を【文字】の〈文字列に〉(123)にしよう
枠「数字が文字に変わりました:{『文字』}」を出力しよう

『数字』を【数字】の〈数字に〉(「123」)にしよう
『計算結果』を【数字】の『数字』+10にしよう
枠「計算結果は{『計算結果』}です！」を出力しよう

『コード』を【数字】の〈コードに〉(「A」)にしよう
枠「Aのコードは{『コード』}ですよ。」を出力しよう

『字』を【文字】の〈文字に〉(65)にしよう
枠「65番の字は{『字』}なんですよ。」を出力しよう
```
