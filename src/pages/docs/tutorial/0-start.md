---

### プログラムとは？

**プログラム**は、コンピューターにやってほしいことを順番に書いた文章です。料理のレシピが「お湯を沸かそう → 麺を入れよう → 3分待とう」のように順番に書かれているように、プログラムも**上から下へ1行ずつ**実行されます。

カナデで書いたプログラムはこんな形です。

```kanade
「こんにちは！」を出力しよう
```

`出力しよう`は「画面に見せよう」という意味です。だからこのプログラムは、画面に`こんにちは！`を表示します。

---

### コードを実際に実行してみる

このドキュメントのコードの箱は、すべて**その場で実行できます。** インストールするものはありません。

1. 上のコードの箱の右上にある**実行**ボタンを押してみてください。
2. 箱の下に**結果**の欄が開き、`こんにちは！`が表示されます。
3. 箱の中の文字を書き換えることもできます。`こんにちは！`を`はじめまして！`に変えて、もう一度実行してみてください。

コードを壊してしまっても心配いりません。ページを再読み込みすれば元に戻ります。まっさらな画面で自由に書いてみたいなら、左の目次の下にある**直接実行してみる**ボタンを押すか、いちばん上のメニューの**プレイグラウンド**へ行ってください。

---

### 複数の行は順番に実行されます

```kanade
「いち」を出力しよう
「に」を出力しよう
「さん」を出力しよう
```

実行すると`いち`、`に`、`さん`が1行ずつ順番に出てきます。行の順番を入れ替えると、出てくる順番も変わります。プログラムはいつも**上から下へ**流れる、と覚えておいてください。

---

### カナデの文の読み方

カナデの文は日本語と同じように、**「何を + どうしよう」** の形になっています。

| 文 | 読み方 |
|---|---|
| `「こんにちは」を出力しよう` | 「こんにちは」**を**画面に**出力しよう** |
| `『点数』を10にしよう` | 『点数』という名札**を**10**に** **しよう** |
| `『点数』に5を足そう` | 『点数』**に**5**を** **足そう** |

文の最後には必ず`〜しよう`、`〜作ろう`のような**動詞**が来ます。この動詞が、コンピューターのやることです。

#### 4つの記号

カナデは、かっこの形を見るだけでそれが何なのかが分かります。この4つを覚えれば、カナデのコードが読めるようになります。

| 記号 | 意味 | 例 |
|---|---|---|
| `「文字」`（かぎかっこ） | 画面に見せる**文字そのもの** | `「こんにちは」` |
| `『名前』`（二重かぎかっこ） | 値を入れておく**名札**（変数） | `『点数』`、`『名前』` |
| `【種類】`（すみつきかっこ） | 値の**種類**（タイプ） | `【数字】`、`【文字列】` |
| `〈機能〉`（山かっこ） | 用意されている**機能**（関数） | `〈文字列に〉()` |

特に`「」`と`『』`は間違えやすいです。`「点数」`は**点数という文字**で、`『点数』`は**点数という名札に入っている値**です。

```kanade
『点数』を100にしよう
「点数」を出力しよう
『点数』を出力しよう
```

1つ目の出力は`点数`という文字を、2つ目の出力は名札に入っている`100`を表示します。

---

### まとまり: コロン（`:`）と字下げ

文の中には「この下のことをまとめてやろう」という意味を持つものがあります。そういう文は最後に**コロン（`:`）**を付け、まとめられる行は**内側に字下げ**して書きます。

```kanade
もし 真 なら:
    「この行はまとまりの中にあります。」を出力しよう
    「この行もまとまりの中にあります。」を出力しよう
「この行はまとまりの外にあります。」を出力しよう
```

- 字下げは**半角スペース4つ**をおすすめします。タブでもかまいませんが、1つのまとまりの中では全部同じだけ字下げしてください。
- 字下げが終わるところで、まとまりも終わります。上の例の最後の行は、まとまりとは関係なくいつも実行されます。

`もし`（条件）や`繰り返そう`（繰り返し）を学ぶときに、このまとまりをよく使います。今は「コロンの次の行は字下げする」とだけ覚えておいてください。

---

### メモを残す: `(参考)`

`(参考)`と書くと、そこから行の終わりまでは**コンピューターが読まないメモ**になります。コードが何をしているのかを人に伝えるときに使います。

```kanade
(参考) 下の行はあいさつを出力します。
「こんにちは！」を出力しよう
「よろしく！」を出力しよう (参考) 行の終わりにもメモを付けられます。
```

---

### エラーが出たとき

コードを書いていると、エラーには必ず出会います。エラーは「ここがおかしいですよ」と教えてくれる**ヒント**なので、怖がらなくて大丈夫です。下のコードは`出力しよう`を`出力しよ`と書き間違えています。実行してみてください。

```kanade fail
「こんにちは」を出力しよ
```

結果の欄に **「1行目で文が途中で終わっています。」** のようなメッセージが出ます。エラーメッセージはたいてい2つのことを教えてくれます。

1. **どこで**: 何行目か（ときには何文字目か）
2. **何が**: 何がおかしいのか

その行に行って、書き間違いがないか、かっこを開いて閉じたかを確かめてください。初心者がよく出会うエラーは次のとおりです。

| こんなメッセージが出たら | ここを確かめてください |
|---|---|
| 文が途中で終わっています | 動詞（`出力しよう`など）に書き間違いがないか |
| 「「」を解釈できません | かぎかっこを開いて閉じたか（`「こんにちは」` ← 両方） |
| 変数『点数』が見つかりません | その名札を先に`にしよう`で作ったか、名前に書き間違いがないか |

もっと多くのエラーと直し方は[付録. よく出会うエラー](/docs/tutorial/common-errors)にまとめてあります。

### 自分のコンピューターで実行するには（後回しでOK）

このドキュメントだけで最後まで学べます。ファイルを読み書きしたり実行ファイルを作ったりと、ブラウザではできないことが必要になったら、そのときに[Hanaランタイム](/docs/hana/intro)をインストールして、`hana run ファイル名.knd`で実行してください。

### 練習問題

**1.** 下のコードを書き換えて、自分の名前であいさつする3行を出力してみましょう。

```kanade
「こんにちは！」を出力しよう
「私の名前はカナデです。」を出力しよう
「よろしくお願いします。」を出力しよう
```

**2.** 下のコードにはエラーが1つあります。実行してメッセージを読み、直してみましょう。

```kanade fail
「今日の天気を出力しよう
```

<summary>答えを見る</summary>

かぎかっこを閉じていないので、カナデは文字がどこで終わるのか分かりません。文字の後ろに`」`を付ければ直ります。

```kanade
「今日の天気」を出力しよう
```

**3.** 下のコードを実行する前に、何がどんな順番で出てくるか予想してみましょう。それから実行して答え合わせをしてください。

```kanade
「最初」を出力しよう
(参考) 「真ん中」を出力しよう
もし 真 なら:
    「まとまりの中」を出力しよう
「最後」を出力しよう
```

<details>
<summary>答えを見る</summary>

`最初`、`まとまりの中`、`最後`の順に出てきます。2行目は`(参考)`で始まってメモになったので、実行されません。

</details>
