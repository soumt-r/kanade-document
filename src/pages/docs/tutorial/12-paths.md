---

`【パス】`モジュールは、`写真/旅行/海.png`のような**パスの文字列**を扱います。つなげたり、フォルダ名とファイル名を取り出したり、拡張子を変えたり、`..`が混ざったパスをきれいに整えたりできます。これらの道具は**文字列だけを触り、コンピューターのファイルには触れない**ので、ブラウザでもそのまま動きます。ファイルを実際に読み書きするのは[Hanaランタイム](/docs/hana/intro)の[`【ファイル】`](/docs/hana/files)モジュールの役目で、二つを組み合わせると便利です。

| 道具 | できること |
| --- | --- |
| `〈結合〉(部品, 部品, …)` | 部品を`/`でつなぎます（空の部品は飛ばし、`/`で始まる部品が来たらそこからやり直します） |
| `〈フォルダ名〉(パス)` | 最後の部品を除いた前の部分を返します（`a/b/c.txt` → `a/b`） |
| `〈ファイル名〉(パス)` | 最後の部品を返します（`a/b/c.txt` → `c.txt`、`a/b/`のように`/`で終わると空の文字列） |
| `〈拡張子〉(パス)` | 最後の部品の拡張子をドット付きで返します（`c.tar.gz` → `.gz`、`.bashrc`に拡張子はありません） |
| `〈拡張子なし名〉(パス)` | 拡張子を除いたファイル名です（`c.txt` → `c`） |
| `〈拡張子変更〉(パス, 拡張子)` | 拡張子を変えます（`「md」`のようにドットがなくてもよく、`「」`なら拡張子をなくします） |
| `〈正規化〉(パス)` | `//`、`.`、`中/..`をたたんできれいにします |
| `〈絶対パスか〉(パス)` | `/`（または`C:/`）で始まるかを`真`/`偽`で教えます |
| `〈構成要素〉(パス)` | 部品のリストに分けます（絶対パスなら先頭が`/`です） |

```kanade
【パス】から〈結合〉と〈ファイル名〉と〈フォルダ名〉を持ってこよう
【パス】から〈拡張子〉と〈拡張子なし名〉と〈拡張子変更〉を持ってこよう

『元』を【文字列】の〈結合〉(「写真」, 「旅行」, 「海.png」)にしよう
『元』を出力しよう
〈フォルダ名〉(『元』)を出力しよう
〈ファイル名〉(『元』)を出力しよう
〈拡張子〉(『元』)を出力しよう
〈拡張子なし名〉(『元』)を出力しよう
〈拡張子変更〉(『元』, 「jpg」)を出力しよう
```

### パスを書くルール

- 部品を区切る文字は`/`です。Windowsのパスのように`\`で書いても`/`として扱い、返すパスはいつも`/`を使います（Windowsも`/`を理解します）。
- 先頭が`C:`のように英字1文字と`:`なら、ドライブとして扱います。`C:/data`は絶対パスで、`C:data`は違います。
- 道具は、パスが実際に存在するかどうかは確かめません。存在しないフォルダのパスでもいくらでも作れます。

### 正規化と分割

`〈正規化〉`は`.`と`//`を消して、`中/..`を打ち消し合わせます。それ以上さかのぼれない相対パスの`..`は残り、`/`の真上へ行く`..`は消えます。全部消えて何も残らないときは`.`です。

```kanade
【パス】から〈正規化〉と〈絶対パスか〉と〈構成要素〉を持ってこよう

〈正規化〉(「a//b/./c/../d」)を出力しよう
〈正規化〉(「../a/../..」)を出力しよう
〈正規化〉(「/../a」)を出力しよう
〈正規化〉(「a/..」)を出力しよう

〈絶対パスか〉(「/data/メモ.txt」)を出力しよう
〈絶対パスか〉(「data/メモ.txt」)を出力しよう

〈構成要素〉(「/data/メモ.txt」)を出力しよう
〈構成要素〉(「data/./メモ.txt」)を出力しよう
```

### エラーになるとき

道具ごとに、受け取る値の数と種類が決まっています。`〈ファイル名〉(1)`のように文字列でない値を渡したり、`〈結合〉()`のように何も渡さなかったりするとエラーになります。

### `【ファイル】`と一緒に

フォルダの中を順に見て拡張子を変えて移すような、実際のファイルを扱う仕事でこれらの道具が活躍します。`【ファイル】`は[Hanaランタイムのドキュメント](/docs/hana/files)で見たとおりブラウザでは使えないので、次のようなスクリプトは自分のコンピューターのHanaランタイムで動かしてみてください。

```kanade fail
【ファイル】から〈一覧〉と〈移動〉を持ってこよう
【パス】から〈結合〉と〈拡張子〉と〈拡張子変更〉を持ってこよう

『名前たち』を【リスト】の〈一覧〉(「写真」)にしよう
『名前たち』の『名前』ごとに繰り返そう:
    『種類』を〈拡張子〉(『名前』)にしよう
    もし(『種類』と「.png」が同じ)なら:
        〈移動〉(〈結合〉(「写真」, 『名前』), 〈結合〉(「写真」, 〈拡張子変更〉(『名前』, 「jpg」)))を実行しよう
```
