Kanade（カナデ）には、よく使う道具をまとめた**標準ライブラリ**が入っています。インポートなしで使えるのは`出力しよう`のような文法と`〈数字に〉()`のような型変換だけで、それ以外の道具は`【モジュール】から〈道具〉を持ってこよう`で必要なものだけ取り出して使います。道具を1つずつ持ってきてもよいですし、`と`でつないで一度にたくさん持ってきたり、モジュールにあるものを`全部`持ってきたりもできます。名前がぶつかるときは、道具1つに限って`〈道具〉を〈新しい名前〉に持ってこよう`のように別名を付けられます。

| モジュール | できること | 道具 |
| --- | --- | --- |
| `【数学】` | 切り上げと切り捨て（もっと多くの計算は11章） | `〈切り上げ〉` `〈切り捨て〉` |
| `【JSON】` | JSONの文字列と値の変換 | `〈パース〉` `〈文字列化〉` |
| `【乱数】` | ランダムな値を選ぶ | `〈実数〉` `〈整数〉` `〈選ぶ〉` `〈シャッフル〉` |
| `【日時】` | 時刻を扱う | `〈今〉` `〈書式〉` `〈読み取り〉` `〈曜日〉` `〈待つ〉` |
| `【正規表現】` | 文字のパターンを探す | `〈検査〉` `〈検索〉` `〈グループ〉` `〈全検索〉` `〈置換〉` `〈分割〉` |

```kanade
【数学】から〈切り上げ〉を持ってこよう
【数学】から〈切り上げ〉と〈切り捨て〉を持ってこよう
【数学】から〈切り上げ〉を〈丸め〉に持ってこよう
【数学】から全部持ってこよう

〈丸め〉(3.2)を出力しよう
〈切り上げ〉(3.2)を出力しよう
〈切り捨て〉(3.8)を出力しよう
```

`全部`はそのモジュールにある道具をすべて持ってきます。ただし、別のモジュールから同じ名前の道具を持ってくると後のものが前のものを上書きするので、名前がぶつかりそうなときは必要なものだけを選んで持ってきてください。

### JSON

`〈パース〉`はJSONの文字列をKanadeの値に変えます。オブジェクトは辞書、配列はリスト、`null`は`空っぽ`になります。逆に`〈文字列化〉`は値をJSONの文字列にします。辞書のキーは文字列で、文字の順に並びます。2つ目の引数にインデントの幅を渡すと、読みやすく整形されます。

```kanade
【JSON】から〈パース〉を持ってこよう
【JSON】から〈文字列化〉を持ってこよう

『文』を「{"名前": "はな", "点数": [90, 80]}」にしよう
『値』を〈パース〉(『文』)にしよう
『値』の「名前」を出力しよう

『辞書』を{「b」:2,「a」:真}にしよう
〈文字列化〉(『辞書』)を出力しよう
〈文字列化〉(『辞書』, 2)を出力しよう
```

### 乱数

`〈実数〉()`は0以上1未満の数、`〈整数〉(最小, 最大)`は2つの数の間（両端を含む）の整数を返します。`〈選ぶ〉`はリストから1つ選び、`〈シャッフル〉`は混ぜた**新しいリスト**を返します（元のリストはそのままです）。実行するたびに結果が変わります。

```kanade
【乱数】から〈整数〉を持ってこよう
【乱数】から〈選ぶ〉を持ってこよう
【乱数】から〈シャッフル〉を持ってこよう

『サイコロ』を〈整数〉(1, 6)にしよう
枠「サイコロは{『サイコロ』}が出ました。」を出力しよう

『メニュー』を【「カレー」, 「ラーメン」, 「うどん」】にしよう
枠「今日は{〈選ぶ〉(『メニュー』)}！」を出力しよう
〈シャッフル〉(『メニュー』)を出力しよう
```

### 日時

時刻は1970年1月1日から経った**秒**（数字）で扱います。`〈今〉()`が現在の時刻を返し、`〈書式〉(時刻, 書式)`で文字列に、`〈読み取り〉(文字列, 書式)`で時刻に戻せます。書式では`YYYY`（年）、`MM`（月）、`DD`（日）、`HH`（時）、`mm`（分）、`ss`（秒）だけが置き換わり、ほかの文字はそのままです。コンピューターに設定されたタイムゾーンを使います。`〈曜日〉(時刻)`は曜日を月曜日の`1`から日曜日の`7`までの数字で教えてくれます。「2月30日」のように存在しない日付を読み取るとエラーになります。`〈待つ〉(秒)`はその時間だけプログラムを止めて待ちます（0秒から3600秒まで、小数も使えます）。ブラウザのプレイグラウンドでも画面が固まらずに待ちます。

```kanade
【日時】から〈今〉を持ってこよう
【日時】から〈書式〉を持ってこよう
【日時】から〈読み取り〉を持ってこよう

『時刻』を〈読み取り〉(「2024-03-05 07:08:09」, 「YYYY-MM-DD HH:mm:ss」)にしよう
〈書式〉(『時刻』, 「YYYY年MM月DD日」)を出力しよう

『今』を〈今〉()にしよう
枠「今は{〈書式〉(『今』, 「HH:mm:ss」)}です。」を出力しよう
```

`〈待つ〉`でゆっくり数えることもできます。

```kanade
【日時】から〈待つ〉を持ってこよう

「3」を出力しよう
〈待つ〉(0.3)を実行しよう
「2」を出力しよう
〈待つ〉(0.3)を実行しよう
「1」を出力しよう
〈待つ〉(0.3)を実行しよう
「発射！」を出力しよう
```

### 正規表現

文字列からパターンを探すときは**正規表現**を使います。道具はどれも先に`(文字列, パターン)`を受け取ります。

- `〈検査〉`：パターンがあるかを`真`/`偽`で教えます。
- `〈検索〉`：最初に合った文字列を返します。なければ`空っぽ`です。
- `〈グループ〉`：最初に合った文字列と、`( )`で囲んだ部分をリストで返します。
- `〈全検索〉`：合った文字列をすべてリストで返します。
- `〈置換〉`：合った所を別の文字列に置き換えます。置き換える文字列の中の`$1`、`$2`は囲んだ部分、`$$`はドル記号です。
- `〈分割〉`：合った所で区切ってリストで返します。

```kanade
【正規表現】から〈検査〉を持ってこよう
【正規表現】から〈全検索〉を持ってこよう
【正規表現】から〈グループ〉を持ってこよう
【正規表現】から〈置換〉を持ってこよう
【正規表現】から〈分割〉を持ってこよう

〈検査〉(「abc123」, 「[0-9]+」)を出力しよう
〈全検索〉(「a1b22c333」, 「[0-9]+」)を出力しよう
〈グループ〉(「2024-03-05」, 「([0-9]+)-([0-9]+)-([0-9]+)」)を出力しよう
〈置換〉(「山田 鈴木」, 「([^ ]+) ([^ ]+)」, 「$2 $1」)を出力しよう
〈分割〉(「りんご, みかん,ぶどう」, 「, ?」)を出力しよう
```

正規表現はGoとJavaScriptが共通で使える文法だけが使えます。文字列の何もない所に合う場合（空の文字列に合うパターン）は、`〈全検索〉`、`〈置換〉`、`〈分割〉`では無視されます。先頭に`(?i)`（大文字小文字を無視）、`(?m)`、`(?s)`を付けてオプションを指定できます。

### 一緒に使ってみよう：月曜日をからかう

複数のモジュールをまとめて持ってくると、こんなものも作れます。`〈曜日〉(時刻)`は月曜日が`1`、日曜日が`7`の数字を返します。明日が月曜日なら、`【JSON】`で読み込んでおいたからかいの言葉の中から1つを`【乱数】`で選んで聞かせます。

```kanade
【日時】から〈今〉を持ってこよう
【日時】から〈曜日〉を持ってこよう
【乱数】から〈選ぶ〉を持ってこよう
【JSON】から〈パース〉を持ってこよう

『からかい』を〈パース〉(「["明日は月曜日ですって…週末はもう伝説になりましたね。", "月曜日が近づいてきます！目覚ましの音を先に聞いておきましょう。", "明日は月曜日！お布団の外は危険ですよ。"]」)にしよう

『明日』を(〈今〉() + 86400)にしよう
『曜日番号』を〈曜日〉(『明日』)にしよう

もし(『曜日番号』が1と等しい)なら:
    〈選ぶ〉(『からかい』)を出力しよう
それ以外なら:
    「明日は月曜日ではありません。今日はからかうネタがありませんね。」を出力しよう
```
