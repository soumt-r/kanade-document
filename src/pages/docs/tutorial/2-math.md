### 計算の記号

| 記号 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` | 足し算 | `7 + 2` | `9` |
| `-` | 引き算 | `7 - 2` | `5` |
| `*` | 掛け算 | `7 * 2` | `14` |
| `/` | 割り算 | `7 / 2` | `3.5` |
| `%` | 余り | `7 % 2` | `1` |

計算した値をそのまま出力するには、**式をかっこで囲んで**出力します。

```kanade
(7 + 2)を出力しよう
(7 / 2)を出力しよう
(7 % 2)を出力しよう
```

`9`、`3.5`、`1`が出ます。割り算は、割り切れないときは小数まで計算します。

計算の結果を名札に入れることもできます。

```kanade
『横』を8にしよう
『縦』を5にしよう
『面積』を『横』 * 『縦』にしよう
枠「面積は{『面積』}です。」を出力しよう
```

### 計算の順番とかっこ

1つの式に計算がいくつもあるときは、学校で習った順番のとおりに計算します。

1. **かっこ**の中をいちばん先に
2. **掛け算・割り算・余り**（`*` `/` `%`）を次に
3. **足し算・引き算**（`+` `-`）を最後に
4. 同じ段階どうしは**左から**

```kanade
(2 + 3 * 4)を出力しよう
((2 + 3) * 4)を出力しよう
(100 / 10 / 5)を出力しよう
```

- `2 + 3 * 4`は掛け算を先にして`2 + 12` = `14`
- `(2 + 3) * 4`はかっこを先にして`5 * 4` = `20`
- `100 / 10 / 5`は左から`10 / 5` = `2`

順番に迷ったら、先に計算したい部分をかっこで囲んでください。かっこを多めに書いても、結果が間違うことはありません。

---

### 余り（`%`）は何に使うの？

余りは思ったよりよく使います。代表的なのが**偶数・奇数の見分け**です。2で割った余りが0なら偶数、1なら奇数です。

```kanade
『数』を17にしよう
『余り』を『数』 % 2にしよう
枠「{『数』}を2で割った余りは{『余り』}です。」を出力しよう
```

`1`が出るので、17は奇数です。（条件によって「偶数」「奇数」と出力する方法は5章で学びます。）

---

### 名札の値を増やす・減らす

名札の値を計算の結果に変えるときは、`にしよう`をもう一度使います。

```kanade
『点数』を50にしよう
『点数』を『点数』 * 2にしよう
『点数』を出力しよう
```

`100`が出ます。右側の`『点数』 * 2`が先に計算され（50 × 2）、その結果がもう一度`『点数』`に入ります。

足し算と引き算はよく使うので、短く書く方法があります。

```kanade
『体力』を100にしよう
『体力』から15を引こう
『体力』に5を足そう
枠「残りの体力: {『体力』}」を出力しよう
```

`残りの体力: 90`が出ます。

| 短い書き方 | 同じ意味 |
|---|---|
| `『x』に5を足そう` | `『x』を『x』 + 5にしよう` |
| `『x』から5を引こう` | `『x』を『x』 - 5にしよう` |

---

### マイナスの数と小数

マイナスの数は、数字の前に`-`を付けます。名札に入っている値の符号を変えたいときは、`0 -`を使います。

```kanade
『気温』を-3にしよう
『反対』を0 - 『気温』にしよう
『反対』を出力しよう
```

`3`が出ます。小数は点を打って書きます（`3.14`）。コンピューターは小数を2進法で扱うので、`0.1 + 0.2`が`0.30000000000000004`のように、ほんの少しずれて出ることがあります。ほとんどのプログラミング言語で同じです。きれいに見せたいなら、12章の`〈四捨五入〉`を使ってください。

---

### 計算できないとき

**0で割る**ことは、どんな数にも決められないのでエラーになります。

```kanade fail
(10 / 0)を出力しよう
```

**「0で割ることはできません。」** のようなエラーが出ます。割る数が0になるかもしれないなら、5章で学ぶ`もし`で先に確かめてください。

**文字と数字**は、そのままでは計算できません。2章で見たように、`〈数字に〉`や`〈文字列に〉`で種類をそろえてください。

```kanade fail
(「10」 + 5)を出力しよう
```

```kanade
(〈数字に〉(「10」) + 5)を出力しよう
```

### よくある間違い

**1. 式をかっこで囲まずに出力する**

`7 + 2を出力しよう`のように書くと、カナデがどこまでが式なのか迷うことがあります。計算式を出力するときは、`(7 + 2)を出力しよう`のようにかっこで囲む習慣をつけてください。

**2. 計算の順番を勘違いする**

平均を求めるときに`『国語』 + 『数学』 / 2`と書くと、割り算が先に計算されて間違った値になります。`(『国語』 + 『数学』) / 2`のようにかっこで囲んでください。

```kanade
『国語』を80にしよう
『数学』を90にしよう
(『国語』 + 『数学』 / 2)を出力しよう
((『国語』 + 『数学』) / 2)を出力しよう
```

1行目は`125`（間違い）、2行目は`85`（正しい）が出ます。

---

### まとめ

| やりたいこと | 書き方 |
|---|---|
| 計算して出力 | `(7 + 2)を出力しよう` |
| 計算して入れる | `『面積』を『横』 * 『縦』にしよう` |
| 先に計算したい部分 | かっこ`( )` |
| 余り | `『数』 % 2` |
| 増やす・減らす | `『x』に5を足そう`、`『x』から5を引こう` |
| 符号を変える | `0 - 『x』` |

もっと多くの数学の道具（切り上げ、切り捨て、平方根など）は、11章と12章で出会います。

### 練習問題

**1.** 1個120円のパンを3個、1個80円の牛乳を2個買いました。全部でいくらか出力してみましょう。

```kanade
(参考) ここに書いてみましょう。
```

<details>
<summary>答えの例</summary>

```kanade
『パン代』を120 * 3にしよう
『牛乳代』を80 * 2にしよう
枠「全部で{『パン代』 + 『牛乳代』}円です。」を出力しよう
```

`全部で520円です。`が出ます。

</details>

**2.** 100分は何時間何分か計算してみましょう。（ヒント: 時間は60で割った商、分は60で割った余りです。商は`『分』 - 『分』 % 60`を60で割るときれいに求められます。）

<details>
<summary>答えの例</summary>

```kanade
『全体』を100にしよう
『分』を『全体』 % 60にしよう
『時間』を(『全体』 - 『分』) / 60にしよう
枠「{『時間』}時間{『分』}分」を出力しよう
```

`1時間40分`が出ます。

</details>

**3.** 下のコードは3教科の平均を求めようとしましたが、間違った値が出ます。直してみましょう。

```kanade
『平均』を70 + 80 + 90 / 3にしよう
『平均』を出力しよう
```

<details>
<summary>答えを見る</summary>

割り算が先に計算されて、`70 + 80 + 30` = `180`が出ます。足す部分をかっこで囲む必要があります。

```kanade
『平均』を(70 + 80 + 90) / 3にしよう
『平均』を出力しよう
```

`80`が出ます。

</details>
