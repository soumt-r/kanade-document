コンピューターは計算がとても得意ですね！数字データを使って四則演算ができますよ。
まず、2つの数字を足してみる簡単な計算をしてみましょうか？

```kanade
『A』を【数字】の10にしよう
『B』を【数字】の20にしよう
『結果』を【数字】の『A』+『B』にしよう

枠「10足す20は{『結果』}です！」を出力しよう
```

変数に保存された数字に直接値を足したり引いたりすることもできますよ。

```kanade
『スコア』を【数字】の50にしよう
『スコア』に10を足そう

枠「スコアが上がりました！現在のスコア：{『スコア』}」を出力しよう
```

今度は引き算をしてみましょうか？

```kanade
『体力』を【数字】の100にしよう
『体力』から15を引こう

枠「攻撃を受けました。残りの体力：{『体力』}」を出力しよう
```

### 掛け算・割り算・余り、そして計算の順序

`*`（掛け算）、`/`（割り算）、`%`（余り）も使えます。1つの式に演算がいくつかあるときは、**掛け算・割り算・余りを先に**計算し、足し算・引き算はその後にします。学校で習った順序のとおりです。同じ種類どうしは左から順に計算します。先に計算したい部分は括弧で囲んでください。

```kanade
(2 + 3 * 4)を出力しよう
((2 + 3) * 4)を出力しよう
(10 - 4 / 2)を出力しよう
(100 / 10 / 5)を出力しよう
(7 % 4 + 1)を出力しよう
```

順に`14`、`20`、`8`、`2`、`4`が出力されます。`2 + 3 * 4`は掛け算を先にして`2 + 12`になり、`100 / 10 / 5`は左から`10 / 5`になります。
