コンピューターは計算がとても得意ですね！数字データを使って四則演算ができますよ。
まず、2つの数字を足してみる簡単な計算をしてみましょうか？

```kanade
『A』を【数字】の10にしよう
『B』を【数字】の20にしよう
『結果』を【数字】の『A』+『B』にしよう

枠「10足す20は{『結果』}です！」を出力しよう
```

変数に保存された数字に直接値を足したり引いたりすることもできますよ。

```kanade
『スコア』を【数字】の50にしよう
『スコア』に10を足そう

枠「スコアが上がりました！現在のスコア：{『スコア』}」を出力しよう
```

今度は引き算をしてみましょうか？

```kanade
『体力』を【数字】の100にしよう
『体力』から15を引こう

枠「攻撃を受けました。残りの体力：{『体力』}」を出力しよう
```
