10章で道具の持ってき方を覚えたら、今度はPythonの標準ライブラリでよく使われる道具をKanadeの言葉に移したものを見てみましょう。どれもファイルやネットワークを使わない純粋な道具なので、ブラウザのプレイグラウンドでもまったく同じように動きます。

| モジュール | できること | 道具 |
| --- | --- | --- |
| `【数学】` | 計算を追加 | `〈平方根〉` `〈べき乗〉` `〈絶対値〉` `〈四捨五入〉` `〈サイン〉` `〈コサイン〉` `〈タンジェント〉` `〈対数〉` `〈円周率〉` `〈最大公約数〉` `〈階乗〉` |
| `【統計】` | 数字のリストを要約 | `〈合計〉` `〈最小値〉` `〈最大値〉` `〈平均〉` `〈中央値〉` `〈標準偏差〉` |
| `【テキスト】` | 文字列を扱う | `〈大文字〉` `〈小文字〉` `〈トリム〉` `〈左埋め〉` `〈右埋め〉` `〈繰り返し〉` `〈逆さ〉` `〈始まるか〉` `〈終わるか〉` `〈連結〉` `〈数える〉` `〈位置〉` |
| `【リスト】` | リストを扱う | `〈並べ替え〉` `〈反転〉` `〈重複除去〉` `〈範囲〉` `〈平坦化〉` `〈小分け〉` `〈ペア〉` |
| `【エンコード】` | 文字列を別の形に | `〈Base64エンコード〉` `〈Base64デコード〉` `〈URLエンコード〉` `〈URLデコード〉` |
| `【ハッシュ】` | 文字列の指紋 | `〈SHA256〉` |
| `【乱数】` | （10章に加えて）固有番号 | `〈UUID〉` |

### 数学

`〈平方根〉`、`〈べき乗〉(底, 指数)`、`〈絶対値〉`は名前のとおりです。`〈四捨五入〉(数, 桁数)`は**0.5を切り上げる**方式（`2.5`は`3`、`-2.5`は`-3`）で、桁数は省略できます。`〈対数〉(数)`は自然対数、`〈対数〉(数, 底)`は底を決めた対数です。三角関数はラジアンを使います。`〈最大公約数〉`と`〈階乗〉`（0から170まで）は整数だけを受け取ります。計算できない値（負の数の平方根、0の対数、大きすぎてあふれる結果）はエラーになります。三角関数や対数などの計算は、エンジンによって最後の桁が違うことがあります。

```kanade
【数学】から〈平方根〉を持ってこよう
【数学】から〈べき乗〉を持ってこよう
【数学】から〈四捨五入〉を持ってこよう
【数学】から〈最大公約数〉を持ってこよう
【数学】から〈階乗〉を持ってこよう

〈平方根〉(2)を出力しよう
〈べき乗〉(2, 10)を出力しよう
〈四捨五入〉(1234.5678, 2)を出力しよう
〈最大公約数〉(12, 18)を出力しよう
〈階乗〉(10)を出力しよう
```

### 統計

数字だけが入ったリストを受け取ります。`〈標準偏差〉`はPythonの`statistics.stdev`と同じ**標本**標準偏差（n-1で割る）なので、値が2つ以上必要です。値が足りないリスト（空のリストの平均など）はエラーになります。

```kanade
【統計】から〈平均〉を持ってこよう
【統計】から〈中央値〉を持ってこよう
【統計】から〈最大値〉を持ってこよう
【統計】から〈標準偏差〉を持ってこよう

『点数』を【70, 85, 92, 60, 88】にしよう
枠「平均{〈平均〉(『点数』)}、中央値{〈中央値〉(『点数』)}、最高{〈最大値〉(『点数』)}」を出力しよう
〈標準偏差〉(『点数』)を出力しよう
```

### テキスト

文字数と位置はすべて**文字単位**（ひらがな1文字が1つ）で数えます。`〈トリム〉`は前後の空白と改行、全角スペースまで取り除きます。`〈左埋め〉(文字列, 幅, 埋める文字)`は、文字列が幅より短いときだけ埋め、切り取りはしません。`〈位置〉`は最初に出てきた場所を1から数えて教え、なければ`空っぽ`です。大文字小文字の変換は、英語のような一般的な文字が対象です。

```kanade
【テキスト】から〈大文字〉を持ってこよう
【テキスト】から〈トリム〉を持ってこよう
【テキスト】から〈左埋め〉を持ってこよう
【テキスト】から〈連結〉を持ってこよう
【テキスト】から〈位置〉を持ってこよう
【テキスト】から〈数える〉を持ってこよう

〈大文字〉(「hello カナデ」)を出力しよう
枠「[{〈トリム〉(「   余白   」)}]」を出力しよう
〈左埋め〉(「7」, 3, 「0」)を出力しよう
〈連結〉(【「りんご」, 「みかん」, 「ぶどう」】, 「、」)を出力しよう
〈位置〉(「あいうえ」, 「う」)を出力しよう
〈数える〉(「banana」, 「an」)を出力しよう
```

### リスト

`〈並べ替え〉`は数字同士または文字列同士だけを並べ替え、**並べ替えた新しいリスト**を返します（元のリストはそのままです）。`〈範囲〉(始め, 終わり)`は終わりまでを**含めて**整数のリストを作り、始めが終わりより大きければ自動で逆順に数えます。3つ目の値は間隔です。`〈重複除去〉`は最初に出てきたものだけを残し、`〈平坦化〉`はリストの中のリストを1段階だけ開きます。

```kanade
【リスト】から〈並べ替え〉を持ってこよう
【リスト】から〈範囲〉を持ってこよう
【リスト】から〈重複除去〉を持ってこよう
【リスト】から〈小分け〉を持ってこよう
【リスト】から〈ペア〉を持ってこよう

〈並べ替え〉(【3, 1, 2】)を出力しよう
〈範囲〉(1, 5)を出力しよう
〈範囲〉(10, 0, (0 - 5))を出力しよう
〈重複除去〉(【1, 2, 1, 3, 2】)を出力しよう
〈小分け〉(【1, 2, 3, 4, 5】, 2)を出力しよう
〈ペア〉(【「あ」, 「い」】, 【1, 2】)を出力しよう
```

### エンコードとハッシュ

文字列はUTF-8として扱います。`〈Base64エンコード〉`と`〈Base64デコード〉`はbase64、`〈URLエンコード〉`と`〈URLデコード〉`はアドレスバーに入れられるよう`%E3%81%82`のように変えます（英数字と`-` `_` `.` `~`以外はすべて変換します）。形式が間違った文字列を読み取るとエラーになります。`〈SHA256〉`は文字列のSHA-256の値を16進数64桁で返します。

```kanade
【エンコード】から〈Base64エンコード〉を持ってこよう
【エンコード】から〈Base64デコード〉を持ってこよう
【エンコード】から〈URLエンコード〉を持ってこよう
【ハッシュ】から〈SHA256〉を持ってこよう
【乱数】から〈UUID〉を持ってこよう

〈Base64エンコード〉(「日本」)を出力しよう
〈Base64デコード〉(「5pel5pys」)を出力しよう
〈URLエンコード〉(「あ い」)を出力しよう
〈SHA256〉(「abc」)を出力しよう
〈UUID〉()を出力しよう
```

`〈UUID〉()`は実行するたびに違うランダムなUUID（`3b241101-e2bb-4255-8caf-4136c566a962`のような文字列）を作ります。
