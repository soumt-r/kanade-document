コードを書いていると、時々思いもよらないエラー（Error）が発生してプログラムが止まってしまうことがありますね。Kanade（カナデ）はこんな時に使える**安全網**を提供していますよ！

`とりあえずやってみよう:` で危険なコードを囲んで、`エラーが発生したなら (『名前』):` でエラーを捕まえることができます。

```kanade
とりあえずやってみよう:
    「安全網の中に入りました！」を出力しよう
    新しい【エラー】(「あっ！問題が発生しました！」)を発生させよう
    「この部分は実行されません。」を出力しよう
発生したら(『エラー』):
    枠「捕まえた！エラーの内容:{『エラー』の『メッセージ』}」を出力しよう
```

上のコードのように無理やりエラーを `新しい【エラー】(「...」)を発生させよう` で投げると、プログラムが止まらずにすぐ『エラーが発生したなら』の構文に移りますよ。

---

### 特定のエラーだけを選んで捕まえる (Exception Filtering)

エラーの種類（タイプ）によって別々に対処したい時もありますよね？ 
そんな時は `【特定のエラー】が発生したなら (『エラー』):` を使って、望むエラーだけをしっかり選び出すことができますよ！ ただしこの方法は、`新しい【特定のエラー】(...)を発生させよう`のように**自分で作ったエラークラス**を投げた時だけ効きます — `10/0`のような計算でエンジンが自動的に出すエラーは特定のタイプで絞り込むことができず、必ず一番下の`発生したら`だけで捕まりますよ。

まず`【エラー】`を継承する自分だけのエラークラスを二つ作ってみましょうか？

```kanade
【決済エラー】を【エラー】を基づいて設計しよう:
    最初に作られる時(【文字列】の『初期メッセージ』)次のようにしよう:
        親の〈最初に作られる時〉(『初期メッセージ』)を実行しよう

【在庫エラー】を【エラー】を基づいて設計しよう:
    最初に作られる時(【文字列】の『初期メッセージ』)次のようにしよう:
        親の〈最初に作られる時〉(『初期メッセージ』)を実行しよう

とりあえずやってみよう:
    新しい【在庫エラー】(「売り切れました！」)を発生させよう
【決済エラー】が発生したら(『エラー』):
    「決済をもう一度確認してください！」を出力しよう
【在庫エラー】が発生したら(『エラー』):
    枠「在庫の問題:{『エラー』の『メッセージ』}」を出力しよう
発生したら(『エラー』):
    (参考)上で捕まらなかった残りのエラーをここで全部処理します。
    『エラー』の『メッセージ』を出力しよう
```

`【在庫エラー】`を投げたので`【決済エラー】`のハンドラーは飛ばされて、`【在庫エラー】`のハンドラーがぴったり実行されますよ！

---

### 締めくくりはいつも (Finally)

エラーが出ても出なくても<strong>"これは無条件に必ず実行して！"</strong>というコードがあれば、`締めくくりはいつも:` を使えばいいですよ。

```kanade
とりあえずやってみよう:
    「安全に実行を開始します。」を出力しよう
発生したら(『エラー』):
    「エラーが出た時だけ実行されます。」を出力しよう
最後はいつも:
    「エラーの発生に関係なくいつも実行されます！」を出力しよう
```

このようにエラー処理を上手にしておけば、どんな突発的な状況でもしっかりと耐えるプログラムを作ることができますよ！

### 関数の中で起こしたエラーを外で捕まえる

エラーは関数の中で投げても、その関数を呼んだ場所の`とりあえずやってみよう`が捕まえてくれます。関数は「これはできません」と知らせるだけで、どう対処するかは呼ぶ側が決めます。

```kanade
〈割る〉を作ろう(【数字】の『あ』, 【数字】の『い』):
    もし(『い』 == 0)なら:
        新しい【エラー】(「0で割れません」)を発生させよう
    (『あ』 / 『い』)を返そう

とりあえずやってみよう:
    〈割る〉(10, 0)を出力しよう
発生したら(『エラー』):
    枠「計算に失敗: {『エラー』の『メッセージ』}」を出力しよう
```

どのエラーがどういう意味か気になったら、[付録: よく出会うエラー](/docs/tutorial/common-errors)を見てください。
