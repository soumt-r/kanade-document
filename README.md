# カナデ(Kanade) 公式ドキュメント & プレイグラウンド

こんにちは！日本語プログラミング言語「カナデ(Kanade)」の公式チュートリアルおよびWeb上で実行できるプレイグラウンドを提供するプロジェクトです。

**カナデ(Kanade)とは？**
カナデは、「コードも、私たちの言葉で！」を目標に作られた韓国語プログラミング言語「ハジャ(Hari)」の**完全互換日本語ローカライズ版**です。
英語や記号中心の既存の言語とは異なり、日本語の自然な文法をそのまま活用してコードを書けるように設計されています。プログラミングを初めて学ぶ方でも、まるで文章を読むようにスラスラと理解できるのが最大の魅力です。
（※AST構造やエンジンはハジャと100%同一です）

このWebサイトはAstroとTailwindCSSを使って作られています。ウェブ上でカナデのコードを直接書いて実行できるように、CodeMirrorエディタをカスタマイズして組み込んでいます。

特に、エディタ内にはカナデ専用のLSP（言語サーバープロトコル）が搭載されています。コードを打ち込むとリアルタイムで構文エラーをチェックし、作成した変数やメソッドを自動で推薦してくれる強力なコード補完（オートコンプリート）機能も一緒に利用できます。

## 開発環境の立ち上げ方

```bash
# パッケージをインストールします
npm install

# ローカル開発サーバーを起動します (http://localhost:4321)
npm run dev

# 静的サイトをビルドします
npm run build
```

## プロジェクトの構造

- `src/pages/docs/`: カナデの基本文法、オブジェクト指向チュートリアル、デザインパターンなどのMarkdown文書が入っています。
- `src/pages/playground.astro`: 広い画面で自由にカナデのコードをテストできるWebプレイグラウンドです。
- `src/utils/kanade/`: カナデ言語のコアエンジン（レクサー、パーサー、インタープリタ）です。ここを修正すると言語の動作が変わります。
- `src/utils/kanade/hariLSP.ts`: エディタに統合されてコード補完と構文検査(Linting)を担当するファイルです。
